# SHADOW WARRIORS — submission handoff

User-selected title: SHADOW WARRIORS. The GitHub repository and internal storage keys retain
the previous Beaconbreak name to preserve links and existing browser saves.
No trademark clearance is claimed for the working title.

## Play loop

Open the same game URL on two devices. Read How to play, then the host creates
a room and shares the eight-character code. The partner joins and presses
I'M READY. Fight the boss, review the transmitted combat profile, spend earned
upgrade points, and both confirm readiness to continue. Defeat offers a retry.
The hundredth victory concludes the story. Leave returns to camp.

## Current features

- Two-device WebSocket co-op, fixed-tick combat and bounded rollback prediction.
- Keyboard and landscape touch input, friendly-fire mitigation, guarding,
  low/high/aerial attacks and a coordinated Duo Strike from mission five.
- 100 generated encounters, four boss behavior families, five weapon tiers,
  and 19 host-selected expedition upgrades shared by the team.
- Ten named chapter antagonists, motivations, opening dialogue, chapter endings,
  a spoiler-gated chronicle and boss-to-boss adaptive combat reports.
- Personal fighter name and mission unlocks saved on each participating device.
- Mission-specific victory recipes composed from ten original action families
  and ten chapter environments, followed by the actual incoming opponent and
  its combat stats. Includes two-person skip voting and a final-boss ending.
- Copyable/shareable invitations with an explicit accept/decline prompt. These
  are private room links, not identity-verified social accounts.
- Refined buttons, paged upgrade cards, explicit room-code validation, distinct
  missing/full-room messages and a how-to-play screen.

## Honest limits

There is no online account or cloud-save service. Browser data must not be
cleared if you want to keep progress. Saves are scoped to the website address;
a different temporary tunnel address has separate browser storage. Use a stable
deployment URL for continued play. A guest can unlock the mission reached
with a more advanced host. This cooperative build trusts the host; it is not
an anti-cheat service. It has no reconnect-in-place or public matchmaking.

The 100 missions reuse an encounter generator, with ten procedural chapter
backdrops; they are not 100 hand-authored environments. Story scenes combine
reusable joint-based movement, chapter scenery and mission text; they are not
100 individually produced films or copied Nekki footage. Parkour is cinematic,
not a playable traversal mode. The fighters are procedural silhouettes. This is not
an equivalent to a large studio's multi-year commercial production.
